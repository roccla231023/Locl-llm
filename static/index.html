UPSTREAMS

中转站

中转站只保存 Base URL；真实 Key 按分组单独管理。点击“管理分组”可逐个拉取模型。

◫

还没有中转站

添加第一个 OpenAI 兼容中转站。

UPSTREAM GROUPS

分组凭证

同一个中转站可以有多个真实 Key；模型路由会绑定到具体分组。

真实 Key 只在这里填写

分组凭证属于中转站，不属于本地访问 Key。客户端只看到本地 Key，日志也不会显示真实 Key。

▦

还没有分组凭证

先添加一个中转站，再为它添加一个或多个真实上游 Key。

CLIENT ACCESS

渠道 Key

每个本地 Key 绑定一个中转站；相同模型名可以在不同渠道重复使用。

渠道 Key 是给客户端使用的本地 Key

它不会替代中转站里的真实上游 Key，也不会把真实 Key 暴露给客户端。客户端只需切换这个 Key，就能切换中转站。

⌘

还没有渠道 Key

创建一个绑定中转站的本地 Key。

ROUTING

模型路由

客户端请求“对外模型名”，网关转成对应的上游模型名；同名模型按渠道分别保存。

对外模型名中转站分组凭证上游模型名状态
◇

还没有模型路由

PRIVACY-SAFE

LOCAL ONLY

设置

安全提示

  • 默认只允许本机访问，不要随意使用 --host 0.0.0.0。
  • 数据库包含真实上游 Key，请妥善保护 data/gateway.db。
  • 不要把数据库、备份文件或真实 Key 提交到 GitHub。
